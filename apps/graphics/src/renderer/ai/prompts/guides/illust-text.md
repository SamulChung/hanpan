# Text

Create text with text.create, restyle it with text.setStyle, turn it into paths with type.createOutlines (select it first).

- `text.create` {x, y, text, rotation?: deg (about x, y), vertical?: bool = false, size?: pt, font?: family, style? (default Regular, or the family's closest style when it has no Regular), color?, keepModel?: bool (as paint.setFill), area?: {width, height, fit?: none|autoHeight|shrinkText, fitMinPercent?}, placeholder?: bool (fill it with placeholder text instead, as the Type tools do with prefs placeholderText), justify?: "auto" (default: the start of each paragraph's direction)|"left"|"center"|"right"|"justifyAll" (point type: aligned on x, so "center" centres each line on the point and "right" ends it there; text.setStyle changes it later), leadingModel?: "romanBaseline"|"emBoxTop", charAlign?: "romanBas
- `text.setStyle` {ids?|id?, font?, style? (font alone: the style is kept when the new family has it, else its closest), size?: pt, leading?: pt|"auto", tracking?: 1/1000 em, justify?: "auto" (the start of each paragraph's direction)|"left"|"center"|"right"|"justifyAll", fill?: colour, keepModel?: bool (as paint.setFill), features?: ["dlig", "-liga", …] OpenType, featureChanges?: ["tnum", "-onum", …] (OpenType features turned on, or with - off, on top of each character's own; its other features are kept), start?: byte, end?: byte} (size/leading are document points after object scaling; with a range: the character attributes style that range and justify the paragraphs it touches; without: all the text) → {ids,
- `type.createOutlines` {} convert the selected text to groups of compound paths (one per glyph); a frame of threaded text leaves its thread with the text it shows → {ids}
