# Hanpan 入門

Hanpan 可以把心智圖整理的內容傳送為 Hangul (HWP) 報告、簡報或 Word 報告，在同一視窗繼續編輯，並讓導圖與文件保持一致。AI 優先使用本機上的 AI。

## 把心智圖傳送到文件

1. 在心智圖工具列點 **傳送到文件**，選擇 HWP 報告、PowerPoint 或 Word 報告。
2. 選擇版式（條列式報告、分章報告、公文編號）、日期和部門，再選 **依導圖原文** 或 **由 AI 擴寫成句子**。
3. 點 **傳送**，文件會在同一視窗的新分頁中開啟。第一次儲存時會詢問儲存位置。

## 同步導圖與文件

- 點 **傳送到文件 › 與連結文件同步**，可查看導圖和 HWP 文件中的變更。
- 導圖中的修改會進入文件，文件中的修改會回到導圖。兩邊改得不同的地方，可選擇以導圖為準、以文件為準或稍後。
- 在文件中寫的內文會被保留。Word 和 PowerPoint 文件目前只能傳送，不能回同步。

## Hanpan 範本

- 首頁的 **Hanpan 範本** 卡片可用 HWP 或 Word 開啟 19 種範本（公文、報告、提案、會議紀錄、企劃書）。
- 在首頁的 **Markdown 轉換器** 卡片中貼上 Markdown 或開啟 .md 檔案，按 **一鍵轉換**，所選格式（HWP、HWPX、Word、ODT、PDF、HTML）會一起產生在同一個資料夾裡。

## Hanpan 工具

- HWP 分頁上方的 **Hanpan 工具** 可整理和檢查公文、依年齡層轉換語氣、標記三色審閱並產生結構化提示詞。
- 修改文件的工具會立即在分頁中顯示結果。不儲存就關閉，檔案保持原樣。

## 設計

- 首頁的 **設計** 卡片可製作海報、卡片新聞、通知和縮圖。
- 點 **複製以貼到文件**，然後在 HWP、Word 或 PowerPoint 分頁按 Ctrl+V，即可作為圖片插入。也可儲存為 PNG 和 PDF。
- 在心智圖中點 **傳送到文件 › 傳送為卡片新聞**，每個主分支產生一張卡片。
- 在設計視窗的 **Make with AI** 中寫下要做的內容並按 **Make**：設定中選擇的 AI 撰寫文字，Hanpan 負責排版與配色，產生可編輯的設計。選取文字方塊後，可用 **Edit with AI** 潤飾、縮短、改得更吸睛或在英韓之間翻譯。復原可回到先前的狀態。

## 本機 AI

- 第一次啟動時，Hanpan 會尋找本機執行的 AI（Ollama、LM Studio、vLLM），如果你還沒有選擇 AI，就使用它。
- 要改用其他 AI，請在 **設定 › AI** 中選擇。
