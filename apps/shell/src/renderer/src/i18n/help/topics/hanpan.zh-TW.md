# Hanpan 入門

Hanpan 可以把心智圖整理的內容傳送為 Hangul (HWP) 報告、簡報或 Word 報告，在同一視窗繼續編輯，並讓導圖與文件保持一致。AI 優先使用本機上的 AI。

## 把心智圖傳送到文件

1. 在心智圖工具列點 **傳送到文件**，選擇 HWP 報告、PowerPoint 或 Word 報告。
2. 選擇版式（條列式報告、分章報告、公文編號）、日期和部門，再選 **依導圖原文** 或 **由 AI 擴寫成句子**。
3. 點 **傳送**，文件會在同一視窗的新分頁中開啟。第一次儲存時會詢問儲存位置。

## 編輯心智圖

- 心智圖上方的功能區分為 **常用**、**插入**、**格式**、**檢視** 索引標籤。Ctrl+F 尋找所有工作表的主題標題，勾選後也尋找備註；Ctrl+H 取代。跳到摺疊分支中的主題時，該分支會展開。
- **插入 › 圖片** 為所選主題加上 PNG、JPG 或 GIF 圖片（最大 10 MB），已有圖片時則移除。**格式 › 排序** 依字母順序排列所選主題的分支，再按一次則反向排列。
- **檢視 › 依層級展開** 只展開到第 1、2 或 3 層，**檢視 › 顯示** 只在畫面上隱藏備註、標籤、連結、圖示或圖片。檔案中的內容保持不變。
- **插入 › 圖示** 開啟圖示面板：優先順序、進度、旗幟、星星、表情和箭頭。每個主題每類圖示只能有一個；再次點選已有的圖示即可移除。點選心智圖上的圖示，可換成同類的其他圖示或將其移除。

## 同步導圖與文件

- 點 **傳送到文件 › 與連結文件同步**，可查看導圖和 HWP 文件中的變更。
- 導圖中的修改會進入文件，文件中的修改會回到導圖。兩邊改得不同的地方，可選擇以導圖為準、以文件為準或稍後。
- 在文件中寫的內文會被保留。Word 和 PowerPoint 文件目前只能傳送，不能回同步。

## Hanpan 範本

- 首頁的 **Hanpan 範本** 卡片可用 HWP 或 Word 開啟 19 種範本（公文、報告、提案、會議紀錄、企劃書）。
- 在首頁的 **Markdown 轉換器** 卡片中貼上 Markdown 或開啟 .md 檔案，按 **一鍵轉換**，所選格式（HWP、HWPX、Word、ODT、PDF、HTML）會一起產生在同一個資料夾裡。

## Hanpan 工具

- HWP 分頁上方的 **Hanpan 工具** 可整理和檢查公文、依年齡層轉換語氣、標記三色審閱並產生結構化提示詞。
- 修改文件的工具會立即在分頁中顯示結果。不儲存就關閉，檔案保持原樣。

## 設計

- 首頁的 **設計** 卡片可製作海報、卡片新聞、通知和縮圖。
- 點 **複製以貼到文件**，然後在 HWP、Word 或 PowerPoint 分頁按 Ctrl+V，即可作為圖片插入。也可儲存為 PNG 和 PDF。
- 在心智圖中點 **傳送到文件 › 傳送為卡片新聞**，每個主分支產生一張卡片。
- 按設計視窗右上角的 **✦ AI helper**，右側會開啟 AI 助手。在 **Make new** 中寫下要做的內容並送出：設定中選擇的 AI 撰寫文字，Hanpan 負責排版與配色，產生可編輯的設計。**Fill this design** 保留目前設計的版面與配色，只把文字方塊換成你的內容；選好範本後出現的 **✦ Fill this template with my content** 也有同樣作用。選取文字方塊後，上方會出現 ✦ 工具列，一鍵潤飾、縮短、改得更吸睛或在英韓之間翻譯。每個結果都有 **Undo**，尚未連接 AI 時可直接在助手中連接。
- 在設計視窗左側的 **Templates**、**Elements**、**Text** 分頁中加入範本、圖形、QR 碼與文字樣式。按住 Shift 點選或在空白處拖曳可選取多個，沿參考線移動，用控制點調整大小與旋轉，按兩下文字方塊即可就地修改。右側設定漸層、陰影、外框與相片濾鏡，**Layers** 分頁設定順序與鎖定，**Resize** 在保留版面的同時變更頁面大小。頁面也可存成 JPG。
- 選取多個後按 **Ctrl+G** 組成群組，即可一起選取與移動；**Ctrl+Shift+G** 取消群組。在元素或空白處按右鍵可開啟複製、貼上、順序與鎖定選單。按兩下相片後拖曳可選擇顯示的部分，並在右側 **Crop** 中放大。**Elements** 分頁中的畫筆可畫出手寫或螢光筆線條，上方的 **Rulers** 用來量位置，按住空白鍵拖曳可移動畫面。透過字型清單中的 **Add a font file…** 加入的字型會存在設計檔裡。
- **Templates** 分頁中有 20 個範本，包括公告卡片、家長通知、活動海報、招募公告、菜單、獎狀與簡報封面等。範本使用Hanpan 內附的字型（Pretendard、Noto Serif KR、Gowun Batang、Black Han Sans、Do Hyeon 等），在任何電腦上開啟都一樣。在 **Elements** 分頁的 **Icons** 中搜尋 "calendar"、"place" 等字詞即可加入線條圖示，並在右側變更顏色與線條粗細。

## 本機 AI

- 第一次啟動時，Hanpan 會尋找本機執行的 AI（Ollama、LM Studio、vLLM），如果你還沒有選擇 AI，就使用它。
- 要改用其他 AI，請在 **設定 › AI** 中選擇。
