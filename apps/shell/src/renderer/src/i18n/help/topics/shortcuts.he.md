# קיצורי מקלדת

לכל עורך יש מקשים משלו, ורק מעט מהם עובדים בכל מקום. זו הרשימה המלאה, מקובצת לפי אפליקציה, עם קיצורי macOS ושל Windows / Linux זה מול זה.

## קראו לפני שמתחילים

### בכל מקום ב-Hanpan (כרטיסיות וחלונות)

| פעולה                                                                       | Windows / Linux              | macOS                        |
| --------------------------------------------------------------------------- | ---------------------------- | ---------------------------- |
| הכרטיסייה הבאה / הכרטיסייה הקודמת                                           | Ctrl+Tab / Ctrl+Shift+Tab    | ⌃Tab / ⌃⇧Tab                 |
| סגירת הכרטיסייה הנוכחית (בדף הבית: החלון, עם שאלה מראש אם יש מסמכים פתוחים) | Ctrl+W                       | ⌘W                           |
| פתיחת ההגדרות — בדף הבית                                                    | Ctrl+,                       | ⌘,                           |
| פתיחת המדריך למשתמש                                                         | F1                           | F1                           |
| בחירת כרטיסייה בשורת הכרטיסיות — כשהמיקוד על כרטיסייה                       | ← / →, Enter, Delete (סגירה) | ← / →, Enter, Delete (סגירה) |

### כל עורך

**מכאן והלאה המקשים שייכים לעורך שלפניכם, ומשתנים כשמחליפים כרטיסיות.**

| פעולה                                         | Windows / Linux | macOS |
| --------------------------------------------- | --------------- | ----- |
| פתיחת המדריך למשתמש — פועל בכל מקום באפליקציה | F1              | F1    |
| כיווץ / הרחבה של סרגל הכלים — בכל עורך        | Ctrl+F1         | ⌥⌘R   |
| רצועה קומפקטית — Docs בלבד                    | Ctrl+Alt+K      | ⌥⌘K   |
| פתיחת גיליון קיצורי המקלדת — רק ב-Word        | Ctrl+/          | ⌘/    |

- **F1 פותח את המדריך הזה**, ולא את גיליון הקיצורים. הוא שייך לתפריט האפליקציה, ולכן הוא עובד באותו אופן מ-Word, מ-Sheets, מ-Slides, מ-PDF או מכרטיסיית הבית.
- **מקש הסרגל הוא `Ctrl+F1`, או `⌥⌘R` ב-macOS.** לחיצה על `F1` בלבד לא עושה דבר — F1 הוא המדריך, ומקש הסרגל אינו משתף איתו במכוון. `Ctrl+F1` מתקבל גם ב-macOS, אך `⌥⌘R` הוא המקש ש-Office fאו Mac משתמש בו.
- **גיליון קיצורי המקלדת הוא של Word בלבד** (`⌘/`). הוא מפרט בדיוק את טבלת Word שלהלן. אין לאף עורך אחר גיליון כזה.

![גיליון קיצורי המקלדת של Word עצמו: הפעולה בשמאל, צירוף המקשים בימין, מקובל לפי קבוצות קובץ, עריכה, עיצוב טקסט, עיצוב פסקה, הוספה, סקירה וכלים, תצוגה](img/word-shortcuts.png)

- **`⌘O`, `⌘S` ו-`⌘P` מיושמים בנפרד מאחורי כל עורך**, והם לא מתנהגים בדיוק כמו זה על זה. ה-`⌘P` של Word מרכיב תחילה תצוגה מקדימה להדפסה, כך שגיליון מודפס אחד שווה בדיוק לעמוד אחד על המסך; של PDF פותח את תיבת הדפסת ה-PDF; ל-Slides ול-Sheets יש שוב משלהם.
- **כל השאר הוא לפי אפליקציה.** כשכרטיסיית Word פעילה, `⌘B` הוא המודגש של Word. כש-Slides פעיל, `⌘B` הוא המודגש של Slides, והתפריט שאליו הוא שייך אינו זה שאתם רגילים אליו. היכן שקיצור פועל רק עם בחירה, או בחלונית מסוימת, עמודת הפעולה אומרת זאת.

## מצב מצגת

- **התחלה**: F5 ב-Word, PDF, Mindmap, HTML ו-Markdown. בגיליון אלקטרוני Ctrl+F5 (מ-A1) או Shift+F5 (מהתא הפעיל). במסמך HWP Ctrl+F5 (שם F5 בוחר תאי טבלה).
- **כניסות אחרות**: ב-Word ‏Ctrl+F5 ו-Shift+F5 פותחים תצוגת קריאה בלי מסך מלא; ב-PDF הם מתחילים בעמוד הנוכחי; ב-HTML הם מציגים בתוך הכרטיסייה.
- **סיום**: Esc או F5. ‏F11 הוא מסך מלא של החלון ואינו משנה את תצוגת המסמך.

## מוסכמות

- עמודת macOS משתמשת בסימנים המוכרים: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control.
- עמודת Windows / Linux כותבת את שמותיהם במלואם: `Ctrl`, `Alt`, `Shift`.
- כאשר ל-GenOffice באמת צריך מקשים שונים בשתי הפלטפורמות, הטבלה מציגה זאת. המקרים הנפוצים הם `⌃H` עבור חיפוש והחלפה (ב-macOS `⌘H` שייך להסתרה), `⌥⌘G` עבור מעבר אל, ומקש הסגירה של Slides.
- קיצור שפועל רק עם בחירה נכתב בעמודת הפעולה במקום לקבל עמודה משלו, כדי שהטבלה תישאר ברוחב של שלוש עמודות.

## Word

ל-Word יש שורת תפריטים מלאה, ולכן קיצורי הקובץ והעיצוב שלהלן פועלים בכל רגע שבו לכרטיסיית Word יש מיקוד, בכל מסמך פתוח. קיצורי העריכה דורשים מסמך שנטען וניתן לעריכה, עם הסמן בתוך הטקסט; הם אינם פועלים בזמן שאתם מקלידים בתיבת החיפוש, בתיבת הנחיה של AI או בכל שדה אחר.

## Sheets

GenOffice Sheets פותח ושומר חוברות עבודה מסוג .xlsx. רוב הקיצורים שלהלן הם הקיצורים הנפוצים בתוכנות גיליונות, כך שרבים מהם כבר יהיו מוכרים לכם.

> **העריכה מנצחת.** כמעט כל קיצור ב-Sheets מתעלם בזמן שאתם עורכים תא או מקלידים ב**שורת הנוסחאות**, כדי שהקלדה, הזזת הסמן ומקש Backspace ישמרו את משמעות העריכה הרגילה של טקסט. אם מקש נראה כמו שאינו עושה דבר, בדקו אתם באמצע עריכה: לחצו תחילה על Esc או Enter, ואז נסו שוב. פקודות שפועלות על הבחירה אינן עושות דבר בזמן שתיבת דיאלוג פתוחה. היכן שקיצור הוא חריג מהכלל הזה, הטבלה אומרת זאת.

שתי המוסכמות הבאות מיוחדות ל-Sheets. `⌘` ו-`⌃` הם אותה משבצת מקשי שינוי — שניהם מתקבלים בכל פלטפורמה, כך ש-`⌘1` ו-`Ctrl+1` הם אותו קיצור. **תא ריק בעמודת Windows / Linux אומר שהקיצור קיים ב-macOS בלבד.**

## Slides

GenOffice Slides הוא עורך מצגות בסגנון PowerPoint. רוב המקשים עושים את אותו דבר בכל מקום שבו אתם נמצאים, אך כמה משנים משמעות לפי המיקוד — בתוך תיבת טקסט, או כש**מסילת התמונות הממוזערות**, **מבנה המבנה** או **ממיין השקופיות** מקבלים מיקוד מקלדת. המקרים האלה מסומנים בעמודת הפעולה.

### קובץ ויישום

| פעולה                    | Windows / Linux | macOS |
| ------------------------ | --------------- | ----- |
| שמירה                    | Ctrl+S          | ⌘S    |
| שמירה בשם                | Ctrl+Shift+S    | ⇧⌘S   |
| פתיחה                    | Ctrl+O          | ⌘O    |
| סגירת הכרטיסייה הנוכחית  | Ctrl+Q          | ⌘W    |
| הדפסה                    | Ctrl+P          | ⌘P    |
| ביטול                    | Ctrl+Z          | ⌘Z    |
| ביצוע חוזר               | Ctrl+Shift+Z    | ⇧⌘Z   |
| ביצוע חוזר (קיצור חלופי) | Ctrl+Y          | ⌘Y    |

סגירת כרטיסייה היא המקום היחיד שבו שתי הפלטפורמות נפצעות לגמרי: ⌘W ב-macOS, וב-Windows וב-Linux זו Ctrl+Q, שיוצאת מכל האפליקציה ולא רק מהכרטיסייה.

שקופית חדשה היא פיצול הפלטפורמות האחרון. לכל פלטפורמה יש מקש משלה והמקש של השנייה אינו עושה דבר: ⇧⌘N ב-macOS, Ctrl+M ב-Windows וב-Linux. ה-`⌘M` אינו יכול לבצע את העבודה ב-macOS משום שזהו מקש המזעור של המערכת.

בחירת הכול מתנהגת לפי המיקוד: כשמסילת התמונות הממוזערות, מבנה המבנה או ממיין השקופיות מקבלים מיקוד, היא בוחרת כל שקופית, ובכל מקום אחר היא בוחרת כל רכיב בשקופית הנוכחית. Tab מעבר בין הצורות שעל השקופית, ורק כאשר הקנבס עצמו מקבל מיקוד.

אלה נטולות מקשי שינוי, ולכן שתי הפלטפורמות קוראות אותן באותו אופן. ↓ ו-↑ הן השורה היחידה שמשתנה לפי המיקוד: בתוך המסמך הן נדיפות את העמוד, אך כשהמיקוד נמצא בסרגל הצד של התמונות הממוזערות הן מתקדמות עמוד שלם. הן אינן עושות דבר בזמן שאתם מקלידים בשדה.

### בחירה ועריכה

| ------------------ | ------------------- | ------------------- |
| מחיקת ההערה שנבחרה | Delete או Backspace | Delete או Backspace |

פעיל רק כאשר הערה, חותמת, השחרה או תמונה נבחרת.

העמודים שנבחרו נצבעים. לחיצה ימנית על אחד מהם או הכרטיסייה „עמוד” מסובבת, מוחקת או מחלצת את כולם יחד; גרירת אחד מהם מזיזה את כולם. Escape או לחיצה רגילה על עמוד מבטלים את הבחירה. ⌘A ו-Delete פועלים כשהמיקוד בסרגל.

| פעולה                     | Windows / Linux | macOS  |

Escape פורם שכבה אחת בכל פעם — תחילה תיבת דיאלוג פתוחה, אחר כך החלונית הצפה של AI, טיוטת טקסט, לוח החיפוש, ולבסוף הבחירה עצמה. כשהסמן נמצא בתיבת החיפוש, Enter ו-⇧Enter עוברים להתאמה הבאה והקודמת, ו-Escape סוגר את הלוח; כשהסמן נמצא בהערת טקסט חדשה, `⌘⏎` מאשר אותה.
