# キーボードショートカット

どのエディターにも独自のキーバインドがあり、どこでも効くのはその一部だけです。このページは全一覧で、アプリケーションごとにまとめ、macOS と Windows / Linux の組み合わせを並べてあります。

## 先に読む

### すべてのエディター

**ここから先のキーは手前にあるエディターのもので、タブを切り替えると変わります。**

| 操作                                             | Windows / Linux | macOS |
| ------------------------------------------------ | --------------- | ----- |
| ユーザー ガイドを開く——アプリのどこからでも      | F1              | F1    |
| リボンを折りたたむ／展開する——すべてのエディター | Ctrl+F1         | ⌥⌘R   |
| リボンをコンパクトに — Docs のみ                 | Ctrl+Alt+K      | ⌥⌘K   |
| キーボードショートカットシートを開く——Word のみ  | Ctrl+/          | ⌘/    |

- **F1 が開くのはこのマニュアル**であり、ショートカットシートではありません。アプリケーションメニューに属するので、Word、Sheets、Slides、PDF、Home タブのいずれからでも使えます。
- **リボンの切り替えは `Ctrl+F1`、macOS では `⌥⌘R` です。** 裸の `F1` を押しても何も起こりません——F1 はマニュアルであり、リボンのキーは意図的にそれを共有しません。macOS でも `Ctrl+F1` は有効ですが、Office for Mac が実際に使うのは `⌥⌘R` です。
- **キーボードショートカットシートは Word だけにあります**（`⌘/`）。ちょうど下の Word の表の内容が載っています。他のエディターにはありません。

![Word だけのキーボードショートカットシート：左が操作、右が組み合わせキーで、ファイル、編集、文字、段落、挿入、校閲とツール、表示のグループに分けられています](img/word-shortcuts.png)

- **`⌘O`、`⌘S`、`⌘P` はエディターごとに個別に実装されており、挙動もまったく同じではありません。** Word の `⌘P` はまず印刷プレビューを組版し、紙の 1 枚が画面上の 1 ページに一致するようにします。PDF の `⌘P` は PDF の印刷ダイアログを開き、Sheets と Slides はまたそれぞれ独自のものになります。
- **残りはアプリケーションごとの扱いです。** Word タブがアクティブなとき `⌘B` は Word の太字です。Slides がアクティブなときは Slides の太字になり、そのキーに対応するメニューは、いつものものとは限りません。選択中や特定のペインでのみ作動する割り当ては、操作の列に記してあります。

## プレゼンテーションモード

- **開始**: Word・PDF・マインドマップ・HTML・Markdown では F5。表計算では Ctrl+F5（A1 から）または Shift+F5（現在のセルから）。HWP 文書では Ctrl+F5（F5 は表のセル選択）。
- **その他の入口**: Word は Ctrl+F5・Shift+F5 で全画面なしの閲覧ビュー、PDF は現在のページから、HTML はタブ内で発表します。
- **終了**: Esc または F5。F11 はウィンドウ自体の全画面で、文書の表示は変わりません。

## 表記の約束

- macOS の列では見慣れた記号を使います: `⌘` Command、`⌥` Option、`⇧` Shift、`⌃` Control。
- Windows / Linux の列では綴って書いています: `Ctrl`、`Alt`、`Shift`。
- GenOffice が二つのプラットフォームで実際に異なるキーを使う必要があるところでは、表に書き分けています。よくあるのは `⌃H` が検索と置換（macOS では `⌘H` が「非表示」用）、`⌥⌘G` が「移動」、そして Slides の閉じるキーです。
- 選択中のみ有効な組み合わせは、専用の列を増やすのではなく操作の列に書き込むので、表は三列のままです。

## Word

Word には完全なメニューバーがあるので、下のファイルと書式の組み合わせは Word タブにフォーカスがある限り使えます。どの文書を開いているかは関係ありません。編集系の組み合わせは読み込み済みの編集可能な文書で、カーソルが本文にあることが必要です。「検索」ボックス、AI プロンプト、その他の入力フィールドで入力している間は作動しません。

## Sheets

GenOffice Sheets は .xlsx のブックを開いて保存します。下のショートカットの大部分は表計算ソフトで一般的なものなので、見覚えのあるものが多いはずです。

> **編集が優先されます。** セルを編集中、または**数式バー**に入力中のとき、Sheets のほぼすべてのショートカットは無視されます。そうすることで、入力、カーソル移動、Backspace が通常のテキスト編集の意味を保つからです。あるキーが何もしないように見えるときは、編集中かどうかを確認してください: まず Esc または Enter を押してから、もう一度試します。選択範囲に作用するコマンドも、ダイアログが開いている間は何もしません。組み合わせがこの規則の例外になる場合は、表に書き記してあります。

Sheets 特有の約束が二つあります。`⌘` と `⌃` は同じ修飾キーの位置です——両方ともすべてのプラットフォームで有効なので、`⌘1` と `Ctrl+1` は同じ組み合わせです。**Windows / Linux のセルが空欄なら、その組み合わせは macOS にしかないことを意味します。**

### 表示

| 操作                            | Windows / Linux | macOS |
| ------------------------------- | --------------- | ----- |
| 拡大                            | Ctrl+=          | ⌃=    |
| 縮小                            | Ctrl+-          | ⌃-    |
| ページに合わせる                | Ctrl+G, P       | ⌃G, P |
| 幅に合わせる                    | Ctrl+G, W       | ⌃G, W |
| 100% に拡大                     | Ctrl+G, Q       | ⌃G, Q |
| ツールボックスの折りたたみ/展開 | Ctrl+F1         | ⌃F1   |
| 段落記号の表示/非表示           | Ctrl+G, T       | ⌃G, T |
| 制御記号の表示/非表示           | Ctrl+G, C       | ⌃G, C |
| ホームタブへ（表の外）          | Ctrl+Shift+H    | ⇧⌘H   |

`Ctrl+N,T` のようにコンマでつないだキーは、前のキーを押して離し、次に後のキーを押すことを意味します。`F5 → S` は F5 でセルブロックを選んでから S を押すことを意味します。`Ctrl+1 … Ctrl+0` は文書の 1～10 番目のスタイルを指し、`Ctrl+Alt+1 … Ctrl+Alt+0` でも同じスタイルが適用されます。 セルブロックを選択しているとき、`Ctrl+Shift+S`（macOS では `⇧⌘S`）はブロック合計です。それ以外では、このキーは名前を付けて保存です。
