# 키보드 단축키

편집기마다 고유한 키 바인딩이 있고, 그중 어디에서나 동작하는 것은 일부뿐입니다. 이 문서는 전체 목록을 앱별로 묶고, Windows와 macOS 조합을 나란히 놓았습니다. 아래 앱 이름은 한판 홈 화면의 이름과 같습니다: Word는 AI 워드, Sheets는 AI 엑셀, Slides는 AI PPT, Markdown은 마크다운, HTML은 AI 웹 문서입니다.

## 먼저 읽으세요

### 한판 어디에서나 (탭과 창)

| 동작                                                          | Windows / Linux            | macOS                      |
| ------------------------------------------------------------- | -------------------------- | -------------------------- |
| 다음 탭 / 이전 탭                                             | Ctrl+Tab / Ctrl+Shift+Tab  | ⌃Tab / ⌃⇧Tab               |
| 지금 탭 닫기 (홈에서는 창 닫기, 열린 문서가 있으면 먼저 물음) | Ctrl+W                     | ⌘W                         |
| 설정 열기 — 홈 화면에서                                       | Ctrl+,                     | ⌘,                         |
| 사용 설명서 열기                                              | F1                         | F1                         |
| 탭 줄에서 탭 고르기 — 탭에 포커스가 있을 때                   | ← / →, Enter, Delete(닫기) | ← / →, Enter, Delete(닫기) |

### 편집기 공통

**여기부터는 지금 앞에 있는 편집기의 키이며 탭을 바꾸면 달라집니다.**

| 동작                                   | Windows / Linux | macOS |
| -------------------------------------- | --------------- | ----- |
| 사용 설명서 열기 — 앱 어디에서나 동작  | F1              | F1    |
| 리본 접기／펼치기 — 모든 편집기 공통   | Ctrl+F1         | ⌥⌘R   |
| 리본 컴팩트하게 — AI 워드 전용         | Ctrl+Alt+K      | ⌥⌘K   |
| 키보드 단축키 시트 열기 — AI 워드 전용 | Ctrl+/          | ⌘/    |

- **F1이 여는 것은 이 매뉴얼**이며 단축키 시트가 아닙니다. 애플리케이션 메뉴에 속하므로 Word, Sheets, Slides, PDF, Home 탭 어디에서나 동작합니다.
- **리본 전환은 `Ctrl+F1`, macOS에서는 `⌥⌘R`입니다.** `F1`만 누르면 아무 일도 일어나지 않습니다. F1은 매뉴얼이고 리본 키는 일부러 그걸 공유하지 않습니다. macOS에서도 `Ctrl+F1`을 사용할 수 있지만, Office for Mac이 실제로 쓰는 키는 `⌥⌘R`입니다.
- **키보드 단축키 시트는 Word에만 있습니다**(`⌘/`). 아래 Word 표의 내용을 그대로 담고 있으며, 다른 편집기에는 없습니다.

![Word만의 키보드 단축키 시트: 왼쪽이 동작, 오른쪽이 조합 키이며 파일, 편집, 텍스트 서식, 단락 서식, 삽입, 검토와 도구, 보기 그룹으로 나뉘어 있습니다](img/word-shortcuts.png)

- **`⌘O`, `⌘S`, `⌘P`는 편집기마다 따로 구현되어** 동작도 완전히 같지 않습니다. Word의 `⌘P`는 먼저 인쇄 미리보기를 조판해 종이 한 장이 화면 한 쪽과 정확히 맞도록 합니다. PDF의 `⌘P`는 PDF 인쇄 대화 상자를 열고, Sheets와 Slides는 또 각자의 방식을 씁니다.
- **나머지는 애플리케이션별로 다릅니다.** Word 탭이 활성 상태일 때 `⌘B`는 Word의 굵게입니다. Slides가 활성 상태일 때 `⌘B`는 Slides의 굵게이고, 그 키가 속한 메뉴도 익숙한 메뉴가 아닙니다. 선택 항목이 있어야 하거나 특정 창에서만 동작하는 조합은 동작 열에 적어 두었습니다.

## 발표 모드

- **시작**: 워드·PDF·마인드맵·HTML·마크다운에서 F5. 스프레드시트에서는 Ctrl+F5(A1부터) 또는 Shift+F5(지금 셀부터). 한글 문서에서는 Ctrl+F5(F5는 표의 셀 블록).
- **다른 입구**: 워드는 Ctrl+F5·Shift+F5로 전체화면 없이 읽기 보기, PDF는 지금 쪽부터, HTML은 탭 안에서 발표합니다.
- **끝내기**: Esc 또는 F5. F11은 창 자체의 전체화면이며 문서 보기를 바꾸지 않습니다.

## 표기 규칙

- macOS 열은 익숙한 기호를 씁니다: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control.
- Windows / Linux 열은 이름을 그대로 적습니다: `Ctrl`, `Alt`, `Shift`.
- GenOffice가 두 플랫폼에서 실제로 서로 다른 키를 써야 하는 곳은 표에 그대로 드러납니다. 흔한 경우는 찾기 및 바꾸기의 `⌃H`(macOS에서는 `⌘H`가 가리기용), 이동의 `⌥⌘G`, 그리고 Slides의 닫기 키입니다.
- 선택 항목이 있어야만 동작하는 조합은 별도 열을 늘리지 않고 동작 열에 적으므로, 표는 세 열로 유지됩니다.

## AI 워드 (Word)

Word에는 완전한 메뉴 막대가 있으므로 아래 파일 및 서식 조합은 Word 탭에 포커스가 있는 동안, 어떤 문서가 열려 있든 동작합니다. 편집 조합은 문서가 열려 있고 편집 가능하며 캐럿이 본문에 있어야 합니다. 찾기 상자, AI 프롬프트, 그 밖의 입력란에 입력하는 동안에는 동작하지 않습니다.

### 파일

| 동작                | Windows / Linux | macOS |
| ------------------- | --------------- | ----- |
| 새로 만들기         | Ctrl+N          | ⌘N    |
| 새 창               | Ctrl+Shift+N    | ⇧⌘N   |
| 열기…               | Ctrl+O          | ⌘O    |
| 저장                | Ctrl+S          | ⌘S    |
| 다른 이름으로 저장… | Ctrl+Shift+S    | ⇧⌘S   |

| 닫기(탭)            | Ctrl+W          | ⌘W    |

⌘P는 브라우저의 인쇄가 아닙니다. Word는 먼저 인쇄 미리보기를 조판해 종이 한 장이 화면 한 쪽과 정확히 맞게 한 뒤, 자체 인쇄 대화 상자를 엽니다.

## AI 엑셀 (Sheets)

GenOffice Sheets는 .xlsx 통합 문서를 열고 저장합니다. 아래 단축키는 대부분 스프레드시트 프로그램에서 흔히 쓰는 것이라, 이미 아는 키가 많을 것입니다.

> **편집이 우선입니다.** 셀을 편집하는 중이거나 **수식 입력줄**에 입력하는 동안 Sheets의 거의 모든 단축키는 무시됩니다. 그래야 입력, 캐럿 이동, Delete 키가 본래 텍스트 편집의 의미를 유지하기 때문입니다. 어떤 키가 아무 일도 하지 않는 것 같다면 편집 중인지 확인해 보세요: 먼저 Esc나 Enter를 누른 뒤 다시 시도합니다. 선택 영역에 작용하는 명령도 대화 상자가 열려 있는 동안에는 아무 일도 하지 않습니다. 이 규칙의 예외인 조합은 표에 적어 두었습니다.

Sheets에만 해당하는 규칙이 두 가지 있습니다. `⌘`와 `⌃`는 같은 수정자 자리입니다 — 둘 다 모든 플랫폼에서 사용할 수 있으므로 `⌘1`과 `Ctrl+1`은 같은 조합입니다. **Windows / Linux 칸이 비어 있으면 그 조합은 macOS에만 있다는 뜻입니다.**

## AI PPT (Slides)

GenOffice Slides는 PowerPoint 방식의 프레젠테이션 편집기입니다. 대부분의 키는 어디서 써도 같은 일을 하지만, 일부는 포커스에 따라 뜻이 달라집니다 — 텍스트 상자 안이거나 **축소판 창**, **개요 창**, **슬라이드 정렬 창**에 키보드 포커스가 있을 때입니다. 이런 경우는 동작 열에 표시되어 있습니다.
