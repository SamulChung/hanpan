# Pintasan papan kekunci

Setiap editor mempunyai pengikatan kekunci sendiri, dan hanya sebahagian kecil daripadanya berfungsi di mana-mana sahaja. Halaman ini ialah senarai penuh, dikelompokkan mengikut aplikasi, dengan pintasan macOS dan Windows / Linux bersebelahan.

## Baca ini dahulu

### Di mana-mana dalam Hanpan (tab dan tingkap)

| Tindakan                                                                                    | Windows / Linux              | macOS                        |
| ------------------------------------------------------------------------------------------- | ---------------------------- | ---------------------------- |
| Tab seterusnya / tab sebelumnya                                                             | Ctrl+Tab / Ctrl+Shift+Tab    | ⌃Tab / ⌃⇧Tab                 |
| Tutup tab semasa (di Laman Utama: tingkap, dengan bertanya dahulu jika ada dokumen terbuka) | Ctrl+W                       | ⌘W                           |
| Buka Tetapan — di Laman Utama                                                               | Ctrl+,                       | ⌘,                           |
| Buka Panduan Pengguna                                                                       | F1                           | F1                           |
| Pilih tab pada baris tab — apabila tab mempunyai fokus                                      | ← / →, Enter, Delete (tutup) | ← / →, Enter, Delete (tutup) |

### Setiap editor

**Mulai dari sini, kekunci milik editor yang berada di hadapan anda, dan berubah apabila anda bertukar tab.**

| Tindakan                                                             | Windows / Linux | macOS |
| -------------------------------------------------------------------- | --------------- | ----- |
| Buka Panduan Pengguna — berfungsi di mana-mana sahaja dalam aplikasi | F1              | F1    |
| Ciutkan / Kembangkan reben — setiap editor                           | Ctrl+F1         | ⌥⌘R   |
| Reben kompak — Docs sahaja                                           | Ctrl+Alt+K      | ⌥⌘K   |
| Buka helaian Pintasan Papan Kekunci — Word sahaja                    | Ctrl+/          | ⌘/    |

- **F1 membuka manual ini**, bukan helaian pintasan. Kekunci itu milik menu aplikasi, jadi ia berfungsi dari Word, Sheets, Slides, PDF mahupun tab Laman Utama.
- **Kekunci suis reben ialah `Ctrl+F1`, atau `⌥⌘R` pada macOS.** Menekan `F1` kosong tidak melakukan apa-apa — F1 ialah manualnya, dan kekunci reben sengaja tidak berkongsi denyut itu. `Ctrl+F1` juga diterima pada macOS, walaupun `⌥⌘R` ialah kekunci yang digunakan oleh Office for Mac.
- **Helaian Pintasan Papan Kekunci milik Word sahaja** (`⌘/`). Ia menyenaraikan tepat jadual Word di bawah ini. Tiada editor lain mempunyai helaian seperti itu.

![Helaian Pintasan Papan Kekunci milik Word sahaja: tindakan di sebelah kiri, pintasan kekunci di sebelah kanan, dikumpulkan mengikut kumpulan Fail, Edit, Pemformatan Teks, Pemformatan Perenggan, Sisip, Semakan & Alat, dan Paparan](img/word-shortcuts.png)

- **`⌘O`, `⌘S` dan `⌘P` dilaksanakan secara berasingan di sebalik setiap editor**, dan mereka tidak berperlakuan sama. `⌘P` milik Word menyusun pratonton cetakan dahulu supaya satu helaian bercetak sama dengan satu halaman pada skrin; milik PDF membuka dialog cetakan PDF; Sheets dan Slides mempunyai milik masing-masing pula.
- **Selebarnya mengikut aplikasi.** Apabila tab Word aktif, `⌘B` ialah Tebal milik Word. Apabila Slides aktif, `⌘B` ialah Tebal milik Slides, dan menu tempatnya tinggal bukan menu yang anda biasa gunakan. Di mana sesuatu pengikatan hanya dicetuskan apabila ada sesuatu yang dipilih, atau di panel tertentu, lajur Tindakan akan menyatakannya.

## Mod persembahan

- **Mula**: F5 dalam Word, PDF, Mindmap, HTML dan Markdown. Dalam hamparan, Ctrl+F5 (dari A1) atau Shift+F5 (dari sel aktif). Dalam dokumen HWP, Ctrl+F5 (di situ F5 memilih sel jadual).
- **Pintu lain**: dalam Word, Ctrl+F5 dan Shift+F5 membuka paparan bacaan tanpa skrin penuh; dalam PDF bermula dari halaman aktif; dalam HTML membentang di dalam tab.
- **Tamat**: Esc atau F5. F11 ialah skrin penuh tetingkap dan tidak mengubah paparan dokumen.

## Konvensyen

- Lajur macOS menggunakan simbol yang biasa: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control.
- Lajur Windows / Linux mengeja nama penuhnya: `Ctrl`, `Alt`, `Shift`.
- Apabila GenOffice benar-benar memerlukan kekunci berbeza pada dua platform, jadual akan menunjukkannya. Kes yang lazim ialah `⌃H` untuk Cari & Ganti (macOS memiliki `⌘H` untuk Sorok), `⌥⌘G` untuk Ke, dan kekunci tutup milik Slides.
- Pintasan yang hanya berfungsi dengan sesuatu yang dipilih ditulis di lajur Tindakan dan bukannya diberi lajur sendiri, supaya jadual itu kekal tiga lajur lebarnya.

## Word

Word mempunyai bar menu penuh, jadi pintasan fail dan pemformatan di bawah berfungsi bila-bila mana tab Word mempunyai fokus, dokumen mana pun yang sedang dibuka. Pintasan penyuntingan memerlukan dokumen yang sudah dimuatkan dan boleh disunting, dengan caret berada dalam teks; ia tidak dicetuskan semasa anda menaip dalam kotak Cari, kotak arahan AI atau medan lain.

## Sheets

GenOffice Sheets membuka dan menyimpan buku kerja .xlsx. Kebanyakan pintasan di bawah ialah pintasan yang biasa digunakan dalam program hamparan, jadi banyak yang mungkin sudah anda kenal.

> **Penyuntingan menang.** Hampir setiap pintasan dalam Sheets diabaikan semasa anda menyunting sel atau menaip dalam **bar formula**, supaya menaip, memindahkan caret dan kekunci Backspace mengekalkan maksud penyuntingan teks biasa. Jika sesuatu kekunci nampaknya tidak melakukan apa-apa, semaklah sama ada anda berada di tengah menyunting: tekan Esc atau Enter dahulu, kemudian cuba lagi. Arahan yang bertindak ke atas pilihan juga tidak melakukan apa-apa semasa dialog terbuka. Di mana satu pintasan menjadi pengecualian kepada peraturan ini, jadual akan menyatakannya.

Dua konvensyen ini adalah khusus kepada Sheets. `⌘` dan `⌃` ialah slot modifier yang sama — kedua-duanya diterima pada setiap platform, jadi `⌘1` dan `Ctrl+1` ialah pintasan yang sama. **Sel Windows / Linux yang kosong bermakna pintasan itu wujud pada macOS sahaja.**

## Slides

GenOffice Slides ialah editor persembahan bergaya PowerPoint. Kebanyakan kekunci melakukan perkara yang sama di mana-mana sahaja anda berada, tetapi beberapa berubah makna mengikut fokus — di dalam kotak teks, atau semasa **baris lakaran kenit**, **kerangka** atau **penyusun slaid** mempunyai fokus papan kekunci. Kes tersebut ditandakan dalam lajur Tindakan.

### Pengiraan jadual

Hanya berfungsi apabila kursor berada dalam sel jadual yang kosong. Ada kekunci berasingan untuk mengira daripada sel di kiri dan sel di atas.

| Tindakan         | Windows / Linux | macOS |
| ---------------- | --------------- | ----- |
| Jumlah kiri      | Ctrl+Shift+H    | ⇧⌘H   |
| Jumlah atas      | Ctrl+Shift+V    | ⌃⇧V   |
| Purata kiri      | Ctrl+Shift+J    | ⌃⇧J   |
| Purata atas      | Ctrl+Shift+B    | ⌃⇧B   |
| Hasil darab kiri | Ctrl+Shift+K    | ⌃⇧K   |
| Hasil darab atas | Ctrl+Shift+N    | ⌃⇧N   |

### Paparan

| Tindakan                                   | Windows / Linux | macOS |
| ------------------------------------------ | --------------- | ----- |
| Zum Masuk                                  | Ctrl+=          | ⌃=    |
| Zum Keluar                                 | Ctrl+-          | ⌃-    |
| Sesuaikan dengan halaman                   | Ctrl+G, P       | ⌃G, P |
| Sesuaikan dengan lebar                     | Ctrl+G, W       | ⌃G, W |
| Zum kepada 100%                            | Ctrl+G, Q       | ⌃G, Q |
| Runtuhkan atau kembangkan kotak alat       | Ctrl+F1         | ⌃F1   |
| Tunjukkan atau sembunyikan tanda perenggan | Ctrl+G, T       | ⌃G, T |
| Tunjukkan atau sembunyikan tanda kawalan   | Ctrl+G, C       | ⌃G, C |
| Pergi ke tab Utama (di luar jadual)        | Ctrl+Shift+H    | ⇧⌘H   |

Kekunci yang ditulis `Ctrl+N,T` bermaksud tekan Ctrl+N, lepaskan, kemudian tekan T. `F5 → S` bermaksud pilih blok sel dengan F5 kemudian tekan S. `Ctrl+1 … Ctrl+0` ialah gaya pertama hingga kesepuluh dokumen; `Ctrl+Alt+1 … Ctrl+Alt+0` menggunakan gaya yang sama. Apabila blok sel dipilih, `Ctrl+Shift+S` (pada macOS `⇧⌘S`) ialah jumlah blok; di luar itu kekunci ini menyimpan sebagai.
