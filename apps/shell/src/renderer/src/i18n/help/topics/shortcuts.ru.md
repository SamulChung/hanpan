# Сочетания клавиш

У каждого редактора свои привязки клавиш, и лишь немногие из них работают везде. Эта страница — полный список, сгруппированный по приложениям, где сочетание для macOS и для Windows / Linux стоят рядом.

## Прочитайте сначала

### В любом месте Hanpan (вкладки и окна)

| Действие                                                                          | Windows / Linux                | macOS                          |
| --------------------------------------------------------------------------------- | ------------------------------ | ------------------------------ |
| Следующая вкладка / предыдущая вкладка                                            | Ctrl+Tab / Ctrl+Shift+Tab      | ⌃Tab / ⌃⇧Tab                   |
| Закрыть текущую вкладку (на «Главной» — окно, с вопросом, если открыты документы) | Ctrl+W                         | ⌘W                             |
| Открыть настройки — на «Главной»                                                  | Ctrl+,                         | ⌘,                             |
| Открыть Руководство пользователя                                                  | F1                             | F1                             |
| Выбрать вкладку на панели вкладок — когда вкладка в фокусе                        | ← / →, Enter, Delete (закрыть) | ← / →, Enter, Delete (закрыть) |

### Любой редактор

**Дальше клавиши относятся к редактору, который открыт у вас, и меняются при переключении вкладок.**

| Действие                                                             | Windows / Linux | macOS |
| -------------------------------------------------------------------- | --------------- | ----- |
| Открыть Руководство пользователя — работает в любом месте приложения | F1              | F1    |
| Свернуть / развернуть ленту — любой редактор                         | Ctrl+F1         | ⌥⌘R   |
| Компактная лента — только Docs                                       | Ctrl+Alt+K      | ⌥⌘K   |
| Открыть лист «Сочетания клавиш» — только Word                        | Ctrl+/          | ⌘/    |

- **F1 открывает это руководство**, а не лист сочетаний. Клавиша относится к меню приложения, поэтому работает из Word, Sheets, Slides, PDF и на вкладке Home.
- **Переключатель ленты — `Ctrl+F1`, а на macOS `⌥⌘R`.** Простое `F1` ничего не делает — F1 это руководство, и клавиша ленты нарочно его не разделяет. `Ctrl+F1` на macOS тоже принимается, но там, где Office fили Mac использует `⌥⌘R`.
- **Лист «Сочетания клавиш» есть только у Word** (`⌘/`). Он перечисляет ровно таблицу Word, приведённую ниже. Ни у другого редактора такого листа нет.

![Собственный лист «Сочетания клавиш» в Word: действие слева, сочетание клавиш справа, сгруппированы по разделам Файл, Правка, Форматирование текста, Форматирование абзаца, Вставка, Рецензирование и инструменты, Вид](img/word-shortcuts.png)

- **`⌘O`, `⌘S` и `⌘P` реализованы отдельно в каждом редакторе**, и ведут себя не вполне одинаково. `⌘P` в Word сначала формирует предварительный просмотр печати, чтобы одна распечатанная страница соответствовала одной странице на экране; в PDF открывает диалог печати PDF; у Sheets и Slides снова свои варианты.
- **Остальное зависит от приложения.** Когда активна вкладка Word, `⌘B` — это «Полужирный» в Word. Когда активен Slides, `⌘B` — это «Полужирный» в Slides, и меню, которому он принадлежит, не то, к которому вы привыкли. Там, где привязка срабатывает только с выделением или в определённой панели, это указано в столбце «Действие».

## Режим презентации

- **Запуск**: F5 в Word, PDF, Mindmap, HTML и Markdown. В таблице — Ctrl+F5 (с A1) или Shift+F5 (с текущей ячейки). В документе HWP — Ctrl+F5 (там F5 выделяет ячейки таблицы).
- **Другие входы**: в Word Ctrl+F5 и Shift+F5 открывают режим чтения без полного экрана; в PDF начинают с текущей страницы; в HTML показывают в вкладке.
- **Выход**: Esc или F5. F11 — полноэкранный режим окна, вид документа он не меняет.

## Соглашения

- Столбец macOS использует привычные символы: `⌘` Command, `⌥` Option, `⇧` Shift, `⌃` Control.
- Столбец Windows / Linux пишет их словами: `Ctrl`, `Alt`, `Shift`.
- Там, где GenOffice действительно нуждается в разных клавишах на двух платформах, таблица это показывает. Типичные случаи: `⌃H` для «Найти и заменить» (на macOS `⌘H` отдан «Скрыть»), `⌥⌘G` для «Перейти к» и клавиша закрытия в Slides.
- Сочетание, которое работает только с выделением, записано в столбце «Действие», а не вынесено в отдельный столбец, чтобы таблица оставалась шириной в три столбца.

## Word

У Word есть полная строка меню, поэтому сочетания для файла и форматирования ниже работают всегда, когда активна вкладка Word, независимо от открытого документа. Сочетания для правки требуют загруженного редактируемого документа с курсором в тексте; они не срабатывают, пока вы набираете текст в поле поиска, в запросе к ИИ или в любом другом поле.

| ----------------- | --------------- | ----- |

## Sheets

GenOffice Sheets открывает и сохраняет книги .xlsx. Большинство приведённых ниже сочетаний — обычные для программ электронных таблиц, так что многие из них вам уже знакомы.

> **Правка важнее.** Почти каждое сочетание в Sheets игнорируется, пока вы редактируете ячейку или набираете текст в **строке формул**, чтобы набор текста, перемещение курсора и Backspace сохраняли обычное значение при работе с текстом. Если клавиша как будто ничего не делает, проверьте, не находитесь ли вы в середине правки: сначала нажмите Esc или Enter, а затем повторите. Команды, действующие на выделение, тоже ничего не делают, пока открыто диалоговое окно. Там, где сочетание является исключением из этого правила, это указано в таблице.

Два соглашения относятся только к Sheets. `⌘` и `⌃` занимают одно и то же место модификатора — обе принимаются на любой платформе, поэтому `⌘1` и `Ctrl+1` — одно и то же сочетание. **Пустая ячейка в столбце Windows / Linux означает, что сочетание есть только на macOS.**

Когда выделен блок ячеек, `Ctrl+Shift+S` (в macOS `⇧⌘S`) — это сумма блока; в остальных случаях эта клавиша сохраняет как.
