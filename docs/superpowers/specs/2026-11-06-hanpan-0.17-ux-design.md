# 한판 0.17 — UX 수정판 (보안키 없음)

작성 2026-11-06. 근거: 11/6 설치판 0.16.0 사용자 점검 "한판 고칠 목록"의 '지금' 묶음 5건과 1차 7건.

## 목적

이미 main에 들어간 AI 포토·AI 일러스트와 함께, 처음 쓰는 사람이 막히거나 어색하게 느끼는 곳을 고쳐 0.17로 배포한다. 보안키는 다음 판으로 미룬다(별도 브랜치 feat/security-key).

완료 기준: 깨끗한 PC에 0.17 설치판을 깔았을 때 아래 12건이 화면에서 확인되고, 소개 페이지에서 그 설치파일을 받을 수 있다.

## 범위 (12건)

'지금' 묶음

1. 개발용 글자 숨기기: 엑셀 "…xlsx을(를) 스트리밍하는 중", 한글 "(173.6ms)" 같은 처리 시간 표시.
2. 탭 우클릭 메뉴: 저장·인쇄가 동작하지 않는 앱(마인드맵·한글·AI 포토·AI 일러스트)에서는 그 항목을 끄거나 실제로 동작하게 한다.
3. 글자 꺾임·스크롤 막대: "다른 이름으로 저장" 단추, 양식 창 "한글로 열기" 단추의 줄바꿈, 워드 리본 아래 가로 스크롤 막대.
4. 저장 안 한 새 문서가 다시 켜면 "empty.docx" 탭으로 되살아나고 최근 목록에 남는 버그(임시 `ieumoffice-empty-package-*` 파일).
5. 첫 실행 안내를 한판 소개로 교체. 원본 제품(GenOffice) 문구·유료 구독 안내 제거. "광고 없음" 약속은 넣지 않는다(대표님 확인 전).

1차 묶음 6. 편집기 "파일" 메뉴 통일: 열기·저장·다른 이름으로 저장·내보내기·인쇄를 AI 파워포인트처럼 각 앱 화면 메뉴에 둔다(워드·엑셀·마크다운·웹 문서·마인드맵·PDF). 탭 줄 ☰ 메뉴는 그대로 둔다. 7. 마인드맵 "한판으로 보내기"를 글자 있는 단추로. 8. AI 도우미 통일: 자리는 모든 앱에서 오른쪽. 기본 모델은 설정 하나로 모든 앱이 같게 — 사용자가 로그인한 계정(Claude·ChatGPT 등)이 있으면 그것, 없으면 PC 모델. 9. 한국어 기본 글꼴: 워드 Calibri·엑셀 Aptos 대신 맑은 고딕(시스템에 없으면 기존 대체 규칙). 엑셀 새 시트 이름 "Sheet1" → "시트1". 10. 디자인 보드: Ctrl+S 덮어쓰기 저장(처음 한 번만 위치를 묻는다), PC에 설치된 글꼴 사용. 11. 한판 양식: 내 문서를 양식으로 저장, 내 양식 추가·삭제. 기본 제공 양식은 지울 수 없다. 12. 홈 정리: 겹치는 카드 짝(AI PDF·PDF 도구, AI 마크다운·마크다운 변환기)을 하나로, 파일 분류 탭 12개를 줄인다. 초안이며 11/10 리뷰에서 확인.

## 하지 않는 것

- 보안키, 회원 다운로드 페이지(tenai.kr/hanpan) 연결.
- 공유하기, 디자인·포토·일러스트 인쇄, 한글 워드 내보내기(2차).
- 앱 화면 구조를 새로 짜는 일. 기존 컴포넌트를 옮기고 묶는 수준에서 끝낸다.

## 방법

main(350555c1)에서 통합 브랜치 `release/0.17-ux`를 만들고, 고치는 파일이 겹치지 않게 앱 단위 5묶음으로 나눠 따로 작업한 뒤 통합 브랜치에 합친다.

| 묶음                         | 항목                                                | 주로 고치는 곳                               |
| ---------------------------- | --------------------------------------------------- | -------------------------------------------- |
| A 셸                         | 2, 4, 5, 12, 3(양식 창 단추)                        | apps/shell                                   |
| B 문서 편집기                | 6·8자리·9(워드)·3(워드) — 워드·마크다운·웹 문서·PDF | apps/docs, markdown, html, pdf               |
| C 표·마인드맵·한글           | 1, 6·8자리·9(엑셀) — 엑셀·마인드맵·한글, 7          | apps/sheets, mindmap, hwp                    |
| D AI 기본 모델 + 디자인 보드 | 8(모델), 10                                         | packages/ai-provider, apps/shell 설정·design |
| E 한판 양식                  | 11                                                  | apps/shell main/hanpan/forms 와 양식 창      |

각 묶음은 시험을 먼저 쓰고(TDD), 자기 워크스페이스의 test·typecheck를 통과시킨 뒤 커밋한다. 합친 뒤 전체 test·typecheck·lint, 설치판 빌드, 설치판 손 점검으로 확인한다.

## 배포

버전 0.17.0. GitHub 빌드 산출물로 설치판을 만들고, 릴리스 공개와 소개 페이지 다운로드 링크(GitHub 릴리스 직접 링크) 변경은 혁준 승인 뒤. 코드 서명이 없어 Windows 경고가 뜨므로 소개 페이지에 실행 방법 안내를 둔다.
