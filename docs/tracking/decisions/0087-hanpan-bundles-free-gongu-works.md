# 0087 한판은 공유마당의 만료·CC BY 저작물만 앱에 담고, 넣을 때마다 출처를 적는다

## 맥락

공유마당(한국저작권위원회, https://gongu.copyright.or.kr)에는 옛 그림, 효과음, 글꼴처럼 학교·기관 문서에 쓸 만한 저작물이 많다. 이용 조건은 저작물마다 다르다: 저작권 보호기간이 끝난 것(만료), 기증, CCL(CC BY, BY-NC, BY-ND …), 공공누리 1~4유형. 한판은 누구나 무료로 받는 프로그램이고, 사용자가 만든 문서는 어디로든 나갈 수 있다(상업적 쓰임, 고쳐 쓰기 포함).

저장소 주인이 "저작권에 자유로운 것 위주로" 공유마당 자료를 앱에 넣자고 했다(2026-11-01). 내려받기도 주인이 승인했다.

## 결정

- **앱에 담는 것은 조건 없이 고쳐 쓰고 상업적으로 써도 되는 것뿐이다**: 만료, 기증(자유이용), 공공누리 0·1유형, CC0, CC BY. 공유마당 그림 찾기의 기본 범위(`docs/plans/gongu-images.md` 4.3)와 같다. 비영리(NC), 변경금지(ND), 동일조건(SA), 공공누리 2~4유형은 담지 않는다. 사용자의 문서가 어디에 쓰일지 앱이 알 수 없기 때문이다.
- **근거는 저작물 페이지의 이용 조건 표시다.** 공유마당이 붙이는 라이선스 `.txt` 첨부는 내려받아지지 않는 일이 있어, 페이지 주소를 `CREDITS.md`에 남긴다.
- **넣을 때 출처를 적는다.** 양식의 그림은 그림 바로 아래에 "출처: 저작자, 「작품」, (발행처,) 공유마당, 이용 조건" 줄이 들어간다(`pictureCredit`). 슬라이드 효과음은 넣은 소리의 이름에 "작품 — 저작자, 공유마당, CC BY"가 들어가 pptx와 함께 간다(`soundEffectCredit`). 만료 저작물은 출처 표시 의무가 없지만 같은 줄을 적는다.
- **무엇을 어디서 받았는지는 파일 곁에 남긴다.** 저작물 페이지 주소와 받은 날을 `CREDITS.md`에 적는다(`apps/shell/src/main/hanpan/pictures/`, `apps/slides/src/main/sound-effects/`).
- **그림은 앱 크기에 맞게 줄인다.** 긴 변 1280px JPEG. 효과음은 고치지 않는다.
- **글 작품은 담지 않고 요약·질문으로 쓴다.** 「운수 좋은 날」(현진건, 1924) 양식은 작품 원문이 아니라 직접 쓴 줄거리 요약과 수업 질문이다. 만료 작품이라도 요즘 표기로 고친 판·해설에는 새 저작권이 있을 수 있어서다.

## 택하지 않은 것

- **긴 배경음악.** 공유마당의 만료 음원은 옛 녹음이 많고, CC BY 곡은 찾고 고르는 데 시간이 더 든다. 이번에는 짧은 효과음만.
- **NC 저작물을 "비영리 문서용"으로 따로 담기.** 사용자가 조건을 지키는지 앱이 알 수 없다.
- **공유마당 화면을 긁어 앱 안에서 바로 찾기.** 그림 찾기는 공식 API로 따로 만든다(`docs/plans/gongu-images.md`).

## 결과

- 한판 양식에 교육 3종: 옛 그림 감상 수업 지도안(인왕제색도·서당·씨름), 옛 그림 전시 안내문(금강전도·추성부도), 「운수 좋은 날」 함께 읽기. 양식은 이제 마인드맵으로도 연다(제목·목록이 가지가 된다, 그림 줄은 빠진다).
- 슬라이드 **삽입 › 효과음**: 국악 효과음 6개(주식회사 아이티앤, CC BY).
- 남은 것: `NOTICE`·`THIRD-PARTY-NOTICES.txt`·도움말에 출처와 쓰는 법 적기(같은 파일을 고치는 글꼴 작업이 끝난 뒤).
