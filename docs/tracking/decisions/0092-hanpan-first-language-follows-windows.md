# 0092 한판의 첫 화면 언어는 운영체제 표시 언어를 따르고, 한판에 없는 언어면 한국어다

## 맥락

한판은 설정에서 언어를 고른 적이 없으면 운영체제와 관계없이 한국어로 켜졌다. 한판을 처음 만들 때 정한 동작이다(8d3fe416). 2026-11-15 베트남 소개에서는 베트남어 Windows에서 내려받은 사람이 처음부터 한국어 화면을 보게 된다. 한국 문서 기능의 기본값(0091)도 화면 언어를 따르므로, 첫 화면이 한국어면 한국 기능까지 켜진 채로 보인다. 설계 문서(`docs/superpowers/specs/2026-11-04-hanpan-vn-securitykey-design.md`)에 없던 결정이라 저장소 주인이 따로 승인했다(2026-11-05).

## 결정

- **설정에서 언어를 고른 적이 없으면 운영체제가 알려 주는 표시 언어 목록(`app.getPreferredSystemLanguages()`)을 앞에서부터 본다.** 한판에 있는 언어(21개)가 나오면 그 언어로 켠다.
- **목록에 한판의 언어가 하나도 없으면 한국어로 켠다.** 한판의 주 사용자는 한국 사용자다.
- **영어는 목록에 정말 영어가 있을 때만 고른다.** `normalizeLang`은 모르는 언어도 영어로 돌려주므로, 한판에 없는 언어(예: 스와힐리어)가 영어로 바뀌지 않게 한다.
- **이렇게 정한 언어는 저장하지 않는다.** 설정에서 언어를 고르기 전까지는 켤 때마다 운영체제를 다시 본다.
- 판단은 `apps/shell/src/main/ui-lang-fallback.ts`의 `fallbackUiLang` 한 곳에서 한다.

## 택하지 않은 것

- **지금처럼 언제나 한국어.** 베트남 사용자가 첫 화면에서 한국어와 한국 기능을 보고, 언어를 바꾸는 곳부터 찾아야 한다.
- **운영체제의 첫 언어 하나만 보기.** 첫 언어가 한판에 없고 둘째가 영어인 사람(예: 스와힐리어, 영어)이 영어 대신 한국어를 보게 된다.
- **첫 실행에 언어 고르기 창 띄우기.** 시연판 일정(2026-11-13) 안에 화면 하나를 더 만들고 21개 언어로 옮겨야 한다.

## 결과

- 베트남어 Windows에서 처음 켜면 베트남어 화면이 뜨고, 한국 문서 기능은 꺼진 채로 시작한다(0091).
- 언어를 고른 적이 없는 기존 사용자 가운데 운영체제 표시 언어가 영어인 사람은 다음 실행부터 영어 화면을 본다. 0091의 기본값에 따라 한국 문서 기능도 함께 꺼진다. 설정 > 일반에서 언어를 한국어로 고르거나 한국 문서 기능 스위치를 켜면 돌아온다.
- 한국어 Windows 사용자에게는 달라지는 것이 없다.
- 화면 시험(e2e)은 `GENOFFICE_LANG`으로 언어를 정하므로 영향이 없다.
