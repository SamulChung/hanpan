# Template fonts

이 폴더의 글꼴은 슬라이드·문서·시트 디자인 템플릿과 디자인 보드가 함께 쓰는 글꼴입니다. 모두 원래
배포처의 파일 그대로이고(잘라 내거나 이름을 바꾸지 않았습니다), SIL Open Font License 1.1 또는
공공누리 제1유형(출처표시)으로 배포됩니다. 공공누리 글꼴의 출처 표시는 각 글꼴의 `*-KOGL.txt`에 있습니다.
PC에 설치하려면 글꼴 파일을 두 번 눌러 설치하면 됩니다. 앱은 글꼴을 Windows에 설치하지 않습니다.

The fonts the slide, document and sheet design templates and the design board share. Every file is the original
distributor's own, unmodified (no subsetting, no renaming), so a document that uses one of these
families opens the same way on a PC that has the real font installed. Each is licensed under the SIL
Open Font License 1.1 or the Korea Open Government License type 1; each family's license text sits
beside its files. The app does not download fonts at run time and does not install them into
Windows.

This folder holds only the font files, their license texts and this readme. The list the app
reads is `packages/ui/src/template-fonts.ts`; it ships once in the installer as
`resources/template-fonts`.

The template fonts below were downloaded on 2026-10-14 and the Gongu fonts on 2026-11-01.
For the template fonts, "license evidence" is the distributor's license file that was read; each one states "This Font Software is licensed under the SIL Open Font License,
Version 1.1" and carries the full license text.

## Free fonts from Gongu (공유마당)

These come from Gongu (https://gongu.copyright.or.kr), the free-works service of the Korea Copyright
Commission, and were downloaded on 2026-11-01 from each font's Gongu page, which states its license.
Only fonts whose terms allow commercial use, shipping the file with the app and embedding it in
documents with no condition beyond attribution were taken: the SIL OFL 1.1, or the Korea Open
Government License (공공누리) type 1, which allows any use, commercial use and redistribution
included, as long as the source is attributed. KoPub World 돋움체 and 바탕체 (no change, rental or
resale without prior approval, and the users' work may be used to promote the font) and 제주명조
(any commercial act such as selling or transferring it for a fee is barred) were left out: their
Gongu pages add conditions beyond attribution. The attribution each KOGL font is owed is written in
its `*-KOGL.txt` file, and repeated in `NOTICE` and the app's help.

Several of these fonts publish each weight as a family of its own (name ID 1 names the weight), so
each such file is listed under the family Office shows for it. Noto Sans KR is listed on Gongu too;
its files were taken from the same Noto CJK commit as Noto Serif KR's.
